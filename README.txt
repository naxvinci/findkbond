채권간편검색기 사용 안내
==================================

■ 이 도구는 무엇을 하나요?
  - 채권 종목코드(예: KR6063621G20)를 입력하면 회사명, 회차, 발행일이 자동으로 입력됩니다.
  - 이어서 DART 증권발행실적보고서에서 해당 회차의 인수기관, 인수수량, 인수금액, 비율을 찾아 표로 보여 드립니다.
  - 회사명과 회차(예: 비씨카드 189-1)를 직접 입력해서도 조회할 수 있습니다.
  - 종목코드를 여러 개 붙여넣어 한 번에 조회할 수도 있습니다 (동시에 10개씩 조회).
  - 결과는 [표 복사] 버튼으로 복사해 엑셀에 바로 붙여넣을 수 있습니다.

■ 파일 구성 (세 파일을 같은 폴더에 두세요)
  - bond_uw.py      조회 기능 본체
  - bond_uw_gui.py  창 화면
  - lookup.bat      더블클릭해서 실행하는 파일

■ 준비 (처음 한 번만)
  1) 파이썬 설치
     - 명령 프롬프트에서 python --version 을 입력해 버전이 나오면 이미 설치된 것입니다.
     - 없다면 python.org 에서 설치하시고, 설치 화면에서 "Add python.exe to PATH"를 꼭 체크해 주세요.
     - 별도의 패키지 설치는 필요 없습니다.

  2) OpenDART API 키 발급 (인수기관 조회용, 무료)
     - opendart.fss.or.kr 에 가입하고 인증키를 신청하면 발급됩니다.

  3) 공공데이터포털 인증키 발급 (종목코드 자동 입력용, 무료)
     - data.go.kr 에 가입한 뒤 "금융위원회_채권기본정보"를 검색해 활용신청을 합니다.
     - 승인 후 마이페이지에서 일반 인증키를 확인할 수 있습니다. (Encoding/Decoding 키 중 어느 쪽을 입력하셔도 됩니다.)
     - 승인 직후에는 키가 반영되기까지 한두 시간 걸릴 수 있습니다.

  ※ 인증키는 사람마다 각자 발급받아 사용해 주세요. 다른 사람의 키를 공유하거나 파일에 적어 두지 마세요.

■ 실행 방법
  - lookup.bat 을 더블클릭하면 창이 열립니다.
  - 처음 조회할 때 위에서 발급받은 키를 입력하는 창이 나옵니다. 한 번 입력하면 PC에 저장되어 다시 묻지 않습니다.

■ 사용 방법
  [종목코드로 조회]
   1) "종목코드" 칸에 코드를 입력하고 엔터를 누릅니다.
      -> 회사명, 회차, 발행일이 자동으로 입력되고, 이어서 인수기관 조회까지 한 번에 진행됩니다.
   2) 조회하는 동안 화면에 진행 막대와 "검색 중... (n초)" 표시가 나타납니다.
   * 입력된 회사명을 고친 뒤에 검색하고 싶으시면 [코드검색] 버튼을 누르세요. 입력까지만 하고 멈춥니다.
     내용을 확인·수정한 다음 [인수기관 조회] 버튼(또는 엔터)을 누르면 검색합니다.

  [회사명/회차로 직접 조회]
   - 종목코드 칸은 비워 두고 회사명, 회차, 발행일(선택)을 입력한 뒤 [인수기관 조회]를 누릅니다.
   - 발행일을 입력하시면 그 날짜 전후의 공시만 확인하므로 매우 빠릅니다. (회사 코드 목록을 받을 필요도 없습니다)
   - 발행일을 입력하지 않으면 최근 2년 안에서 찾기 때문에 오래 걸립니다. 가능하면 입력해 주세요.

  [여러 개 한 번에 조회]
   - [여러 개 일괄 조회] 버튼 -> 종목코드를 붙여넣기 (한 줄에 하나씩, 공백이나 쉼표로 구분해도 됩니다)
   - [일괄 조회]를 누르면 결과가 한 표로 모이고, [표 복사]로 엑셀에 붙여넣을 수 있습니다.
   - 한 번에 수십 개 정도까지는 문제없지만, 수백 개를 넣으면 하루 호출 한도에 걸릴 수 있습니다.

■ 표 복사
  - 결과 표에서 행을 클릭(Shift/Ctrl+클릭으로 여러 행 선택, Ctrl+A로 전체 선택)한 뒤 Ctrl+C를 누르면 복사됩니다.
  - 엑셀에 바로 붙여넣으실 수 있습니다. 전체를 복사하면 제목 줄도 함께 복사됩니다.
  - 우클릭 메뉴로도 복사할 수 있고, [표 복사] 버튼도 그대로 사용할 수 있습니다.

■ 회사명 별칭 (종목명과 DART 회사명이 다를 때)
  - 일부 회사는 종목명과 DART 등록 이름이 다릅니다. 예) 씨제이제일제당 -> CJ제일제당
  - 씨제이/CJ, 에스케이/SK, 엘지/LG, 케이비/KB, 엔에이치/NH 등 흔한 경우는 자동으로 바꿔서 찾습니다.
  - 그 외에는 [별칭 관리] 버튼에서 "입력한 이름 -> DART 등록 이름"을 등록해 두시면 이후 자동으로 적용됩니다.
  - 종목코드로 채워진 회사명을 직접 고쳐서 검색에 성공하면, 별칭으로 저장할지 물어봅니다.
  - 별칭은 사용자 폴더의 .dart_bond_lookup\aliases.json 에 저장됩니다. 이 파일을 다른 분께 복사해 드리면 같은 별칭을 쓸 수 있습니다.

■ 국고채 검색
  - 메인 창 위쪽의 [국고채 검색] 탭을 누릅니다. (별도 창이 열리지 않고 같은 창에서 전환됩니다)
  - 국고채 회차를 붙여넣으면 (예: 25-4ㄱ, 25-6, ㅎ,25-10, (26-5), 26-7) ) 불필요한 글자는 무시하고 회차만 뽑아서 찾습니다.
  - 결과는 채권종목코드, 채권종목명, 발행일, 만기일 순으로 표시됩니다.
  - 결과 표는 마우스로 드래그해서 선택한 뒤 Ctrl+C로 복사할 수 있습니다. 종목코드를 더블클릭하면 그 코드만 선택됩니다.
  - [표 복사]는 표 전체를, [종목코드만 복사]는 종목코드만 한 줄씩 복사합니다. (일괄 조회에 바로 붙여넣을 수 있습니다)
  - 물가채와 원금분리채는 기본으로 제외하며, 필요하면 [물가채 포함], [원금분리채 포함]을 각각 체크해 주세요.
  - 국고채 목록은 하루에 한 번 받아 저장해 두므로, 같은 날 다시 검색하면 바로 나옵니다.
  - 찾지 못한 회차는 표 위쪽 안내 문구에 따로 표시됩니다.

■ 바탕화면 바로가기 (선택)
  - make_shortcut.bat 을 더블클릭하면 바탕화면에 아이콘이 있는 [채권간편검색기] 바로가기가 만들어집니다.
  - bond_icon.ico 는 같은 폴더에 두어 주세요. (창 왼쪽 위 아이콘으로도 쓰입니다)

■ 일반 채권 검색
  - [일반 채권 검색] 탭에서 종목명이나 표준코드의 일부를 입력하고 엔터를 누릅니다.
    예) 수산금융  /  kr1035  -> 이름이나 코드에 해당 글자가 들어가는 모든 채권이 표로 나옵니다.
  - 쉼표나 줄바꿈으로 여러 개를 넣으면 모두 찾습니다. 12자리 표준코드만 넣으면 바로 조회합니다.
  - 표시 항목: 종목명, 표준코드, 채권종류, 채권구분, 통화, 발행금액, 발행일, 만기일, 지급방법, 지급주기,
    표면금리, 민평금리, 기준금리, 신용등급, 공사모, 순위구분, 보증유형
    (공공데이터포털에서 제공하지 않는 항목은 빈칸으로 표시되며, 결과 위에 빈 항목 이름이 안내됩니다.)
  - 이름(종목명·발행기관)으로 검색하면 서버에서 바로 찾아 1초 안팎에 나옵니다. 목록을 미리 받을 필요가 없습니다.
  - 표준코드의 일부(예: kr1035)로 검색할 때만 전체 채권 목록(약 3만 건)을 하루 한 번 내려받습니다. (4~10초 정도)
    이후에는 PC에 저장된 목록으로 바로 검색되며, 최신 목록이 필요하면 [목록 새로고침]을 누르세요.
  - 신용등급은 신용평가사별 값이 같으면 하나만, 다르면 "KIS AA+ / NICE AA" 처럼 함께 표시됩니다.
  - 채권구분·지급방법처럼 어떤 항목을 가리키는지 맞지 않는 열이 있으면, 사용자 폴더의 .dart_bond_lookup\columns.json 에
    {"채권구분": ["pclrBondKcdNm"], "지급방법": ["bondIntTcdNm"]} 형식으로 적어 주세요. ([원본 필드 보기]에서 항목 이름을 볼 수 있습니다.)
    민평금리·기준금리는 공공데이터포털이 제공하지 않아 빈칸으로 나옵니다.
  - 열 제목을 누르면 정렬되고, 칸을 더블클릭하면 그 칸의 값이 복사됩니다. Ctrl+C로 선택한 행을 엑셀에 붙여넣을 수 있습니다.
  - [원본 필드 보기]는 공공데이터포털이 준 항목 이름을 보여 줍니다. 표의 빈 항목을 맞출 때 사용합니다.

■ 참고 사항
  - 종목코드 정보는 공공데이터포털에서 하루 늦게 반영되므로, 아주 최근에 발행된 종목은 조회되지 않을 수 있습니다.
  - 만기가 지난 채권은 종목코드 조회가 되지 않을 수 있습니다.
  - 한 번 조회한 종목코드는 PC에 저장되어 다음부터 더 빠르게 나옵니다.
  - 한 번 읽은 DART 공시(인수기관 표)도 PC에 저장되어, 같은 종목을 다시 조회하거나 같은 공시에 든 다른 회차를 조회하면 바로 나옵니다.
  - 국고채 검색은 서버에서 필요한 종목만 바로 찾습니다. 프로그램을 열 때 미리 받는 것은 없어서 처음부터 빠르게 열립니다.
  - 저장 위치: 사용자 폴더의 .dart_bond_lookup 폴더 (키, 조회 기록, 채권 목록, 읽은 공시)

■ 문제가 생기면
  - 창이 열리지 않으면 명령 프롬프트에서 아래를 실행해 오류 내용을 확인해 주세요.
        python bond_uw_gui.py
  - "종목코드 조회 실패"가 나오면 공공데이터포털 활용신청이 승인되었는지, 인증키를 정확히 입력했는지 확인해 주세요.
  - 회사를 찾지 못한다는 메시지가 나오면 DART에 등록된 정식 회사명으로 입력해 주세요.
    (예: 농협캐피탈 -> 엔에이치농협캐피탈)
  - 오류 메시지는 화면 그대로 복사해서 담당자에게 전달해 주세요.
